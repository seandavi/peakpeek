# PeakPeek

**A peak file at a glance.** Drop in BED, narrowPeak or CSV peak files, or paste URLs, and
PeakPeek shows how many peaks there are, how wide, on which chromosomes, and what's wrong
with each file, side by side. Open `index.html` by double-clicking it: no server, no
install. Uploaded files never leave your computer.

**Status: specified, being built.** [`SPEC.md`](SPEC.md) is the source of truth, and its
§8 tracks the issues. Decisions are in [`adr/`](adr/), and what was done and how it was
checked is in [`LEDGER.md`](LEDGER.md). To run the tests, double-click `test.html`.
